# Инструкция по выполнению упражнений

> **Для кого:** студент слоя Middle (уже пишешь React/TS, интервью).  
> **Цель:** закрепить тему практикой — предсказывать вывод, реализовывать функции, исправлять баги.

Азбука JS: [`junior/sandbox/HOW_TO_PRACTICE.md`](../../junior/sandbox/HOW_TO_PRACTICE.md). Азбука TS без React: [`typescript/sandbox/HOW_TO_PRACTICE.md`](../../typescript/sandbox/HOW_TO_PRACTICE.md).

---

## Что такое sandbox

Команды ниже запускаются **из корня репозитория** `js_course/`.

```
middle/sandbox/
├── js_sandbox/    ← упражнения на чистом TypeScript (Node.js + браузер)
└── next_sandbox/  ← упражнения в контексте React / Next.js
```

Для каждой темы курса есть два файла:

| Файл | Содержание |
|---|---|
| `exercises.ts` | Задания с `// TODO:` — твой рабочий файл |
| `solutions.ts` | Решения с пошаговыми объяснениями — смотри **после** попытки |

---

## Предварительная настройка

**Требования:**
- Node.js 18+
- VS Code с расширением [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)

**Установка зависимостей** (один раз из корня репозитория):

```bash
npm install
```

## Режим 1 — Терминал (быстрый старт)

Подходит для быстрой проверки без открытия браузера.

```bash
# Запустить упражнения (Раздел 1 выводит предсказания автоматически)
npx tsx middle/sandbox/js_sandbox/topics/topic_1/exercises.ts

# Запустить эталонные решения
npx tsx middle/sandbox/js_sandbox/topics/topic_1/solutions.ts
```

**Рабочий цикл:**

```
1. Открой exercises.ts
2. Прочитай задание
3. Раздел 1 (предсказание): запиши ответ в комментарий // Вывод: ?
4. Раздел 2–4 (реализация): напиши код вместо throw new Error(...)
5. Раскомментируй нужный вызов в секции ЗАПУСК (внизу файла)
6. Запусти: npx tsx exercises.ts
7. Проверь результат
8. Сверься с solutions.ts
```

---

## Режим 2 — Браузер (рекомендуется)

Интерактивный: кнопка запускает задание, вывод появляется прямо на странице.  
Не нужно редактировать секцию ЗАПУСК — всё управляется кнопками.

### Шаг 1 — Запустить компилятор

Открой терминал в корне репозитория и запусти:

```bash
npm run ts:watch
```

Компилятор следит за всеми `.ts` файлами в `js_sandbox/` и при каждом сохранении автоматически обновляет `.js` файлы. Оставь этот терминал работать в фоне.

```
Первый запуск выведет что-то вроде:
  Starting compilation in watch mode...
  Found 0 errors. Watching for file changes.
```

### Шаг 2 — Открыть HTML-страницу

В VS Code найди файл:

```
middle/sandbox/js_sandbox/topics/topic_1/browser/index.html
```

Кликни правой кнопкой → **«Open with Live Server»**.

Откроется браузер по адресу `http://127.0.0.1:5500/...`.

### Шаг 3 — Работать с заданиями

На странице — карточка для каждого задания:

```
┌─────────────────────────────────────────────────────┐
│  1.1  Базовый порядок: Call Stack → Microtask → ...  │
│  Запусти и запомни вывод. Почему C появляется...     │
│                                                      │
│  [▶ Запустить]  [✕]                                  │
│                                                      │
│  A                                                   │
│  D                                                   │
│  C   ← microtask                                     │
│  B   ← macrotask                                     │
└─────────────────────────────────────────────────────┘
```

**Рабочий цикл:**

```
1. Прочитай описание задания на карточке
2. Раздел 1: подумай — что выведет код? Запомни свой ответ
3. Нажми ▶ Запустить — сравни с реальным выводом
4. Раздел 2–4: открой exercises.ts, реализуй функцию
5. Сохрани файл → tsc компилирует автоматически (~1 сек)
6. Live Server перезагружает страницу
7. Нажми ▶ Запустить — проверь результат
8. Если ошибка — читай её текст, исправляй, повторяй
```

> **Совет:** держи VS Code и браузер рядом. Редактируй слева, смотри результат справа.

## Как читать exercises.ts

Каждый файл разбит на разделы:

```
РАЗДЕЛ 1 — Предсказание вывода
  Задания, где нужно угадать порядок console.log ДО запуска.
  Код уже написан — твоя задача объяснить, что произойдёт.

РАЗДЕЛ 2 — Реализация утилит
  Функции с заглушкой: throw new Error("Not implemented")
  Твоя задача — написать тело функции.

РАЗДЕЛ 3 — Найди и исправь баг
  Функция brokenXxx работает, но неправильно.
  Реализуй fixedXxx / processXxx с исправлением.

РАЗДЕЛ 4 — Паттерны (продвинутый)
  Реализация production-паттернов из курса.
  Есть TODO-подсказки внутри функции.
```

## Как читать solutions.ts

Открывай solutions.ts **только после** собственной попытки.

Каждое решение содержит:

```typescript
/**
 * Решение 1.2 — Вывод: 4 → 1 → 2 → 3
 *
 * Пошаговая трассировка:
 *  1. Promise.resolve().then(fn1) → Microtask Queue: [fn1]
 *  2. console.log("4")            → вывод сразу
 *  --- синхронный код закончен ---
 *  3. fn1 выполняется: вывод "1", fn_2 → в очередь: [fn_2]
 *  ...
 *
 * Ключевое: fn_2 встаёт в очередь ВО ВРЕМЯ выполнения fn1.
 */
```

Запусти solutions.ts — он выводит все решения с ожидаемыми значениями:

```bash
npx tsx middle/sandbox/js_sandbox/topics/topic_1/solutions.ts
```

## Типичные ошибки

### `❌ Not implemented`

```
Error: Not implemented
```

Функция ещё не реализована. Замени `throw new Error("Not implemented")` своим кодом.

---

### `❌ Cannot find module '../exercises.js'`

```
Failed to load module script: Expected a JavaScript module script ...
```

`tsc` ещё не скомпилировал файл. Запусти `npm run ts:build` или проверь что `npm run ts:watch` работает в терминале.

---

### `❌ Страница не обновляется автоматически`

Live Server работает только если файл открыт через него. Убедись что в строке браузера адрес начинается с `http://127.0.0.1:5500/` а не `file:///`.

---

### `⚠ Задание зависает вкладку`

Некоторые задания (например, `buggyLoop`) специально написаны с бесконечным циклом — **не нажимай кнопку «Запустить»** для них. Такие задания помечены жёлтым предупреждением ⚠.

## Порядок прохождения

```
Для каждой темы курса:

1. Прочитай тему в topics/section_*.md
   └── Теория → Паттерны → Вопросы интервью

2. Открой js_sandbox/topics/topic_N/exercises.ts
   └── Изучи задания, не смотря в solutions

3. Запусти браузерный раннер (npm run ts:watch + Live Server)
   └── Раздел 1: предсказывай → проверяй
   └── Раздел 2–4: реализуй → проверяй

4. Если застрял — подсмотри подсказку (Hint) в задании

5. Открой solutions.ts — сравни подход
   └── Обрати внимание на объяснения, а не только на код

6. Запусти solutions.ts в терминале — убедись что понимаешь каждый вывод

7. (Опционально) Открой next_sandbox/lessons/topic_N/exercises.ts
   └── Задания в контексте React/Next.js
```

## Структура файлов быстрый справочник

```
middle/sandbox/js_sandbox/topics/topic_1/
├── exercises.ts          ← редактируй этот файл
├── solutions.ts          ← смотри после попытки
└── browser/
    └── index.html        ← открывай через Live Server
```

```bash
# Запуск компилятора (фоновый процесс)
npm run ts:watch

npm run ts:build

# Запуск в терминале (без браузера)
npx tsx middle/sandbox/js_sandbox/topics/topic_1/exercises.ts
npx tsx middle/sandbox/js_sandbox/topics/topic_1/solutions.ts
```
