Раздел 2 — Реализация утилит


  

    

      2.1
      delay(ms)
    

    

      Promise, резолвящийся через ms миллисекунд.
      Реализуй в exercises.ts, сохрани — tsc скомпилирует автоматически.
    

    

      
      
    

    

  


  

    

      2.2
      runSequentially(tasks)
      требует delay
    

    

      Строго по очереди: 3 задачи по 100/50/30ms → результат
      ["a","b","c"], время ≈ 180ms.
    

    

      
      
    

    

  


  

    

      2.3
      runWithConcurrency(tasks, limit)
      требует delay
    

    

      6 задач × 100ms, limit=2 → worker pool → время ≈ 300ms
      (вместо 600ms последовательно).
