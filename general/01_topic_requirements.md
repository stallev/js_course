# Требования к содержанию разделов курса

> **Курс:** JavaScript для Middle FullStack Interview (Next.js · React · TypeScript)  
> **Назначение документа:** Стандарт качества и полноты каждого раздела. Каждая тема обязана соответствовать всем пунктам своего блока требований.

---

## Требование к структуре и целостности курса

> Курс обязан давать **логичную, сквозную структуру** — каждая тема опирается на предыдущие и подготавливает к следующим. Обучающийся формирует **связное и целостное представление** о JavaScript как системе, а не набор разрозненных фактов.

### Принципы связности

| Принцип | Описание |
|---------|----------|
| **Сквозные связи** | Каждая тема обязана явно ссылаться на предыдущие темы фразами *"Как мы видели в теме X..."* или *"Это объясняет паттерн из темы Y..."* |
| **Предварение следующего** | В конце каждой темы — блок *"Что дальше"* — одно-два предложения о том, как тема связана со следующей |
| **Нарративная дуга раздела** | Каждый раздел имеет вводный абзац, объясняющий *почему* именно эти темы сгруппированы вместе |
| **Единый стек-контекст** | Next.js / React / TypeScript присутствуют в каждой теме как конкретные проявления теоретических концепций |
| **Прогрессия сложности** | Внутри раздела темы идут от фундаментальных к прикладным |

### Навигационные маркеры (обязательны для каждой темы)

- `← Предыдущая тема: [N — Название]` — в начале раздела теории
- `→ Следующая тема: [N — Название]` — в конце раздела теории
- `🔗 Связь с темой X` — инлайн-ссылки внутри объяснений
