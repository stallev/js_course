## По разделам

### Раздел 1 — Движок и среда выполнения
*Как JavaScript работает под капотом*

```
Тема 1  🔴  Event Loop
Тема 2  🔴  Hoisting и TDZ
Тема 3  🔴  Scope и замыкания
```

**Почему с этого начинать:** Без Event Loop нельзя понять async. Без Hoisting/TDZ — объяснить баги с переменными. Без замыканий — понять хуки React. Это фундамент всего остального.

---

### Раздел 2 — Типы и данные
*Как JS хранит и преобразует данные*

```
Тема 4  🔴  Приведение типов
Тема 5  🔴  Значение vs Ссылка
Тема 6  🔴  null / undefined / NaN
```

**Почему важно:** Неявное приведение и мутация по ссылке — источник большинства скрытых багов в JS-коде. На Middle-интервью обязательно покажут "магический" код с `==`.

### Раздел 3 — Функции
*Функции как первоклассные объекты*

```
Тема 7  🔴  Контекст this
Тема 8  🔴  Замыкания на практике
Тема 9  🔴  map / filter / reduce
Тема 10 🟡  Каррирование
Тема 11 🟢  Генераторы
```

**Почему важно:** `this` и замыкания — самые частые темы на JS-интервью. map/filter/reduce — ежедневный инструмент. Каррирование выделяет кандидата. Генераторы — бонус.

### Раздел 4 — ООП и прототипы
*Объектно-ориентированная модель JS*

```
Тема 12 🔴  Прототипная цепочка
Тема 13 🔴  Классы ES6
Тема 14 🟢  Property Descriptors
```

**Почему важно:** Классы используются в TypeScript-коде ежедневно. Прототипы объясняют как классы работают под капотом. Property descriptors — бонус, показывает глубину знаний.
