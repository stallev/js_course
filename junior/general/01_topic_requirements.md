# Требования к темам курса Junior

> **Курс:** JavaScript для Junior  
> **Стек:** чистый JavaScript (браузер + Node), без TypeScript и React  
> **Назначение:** стандарт качества каждой темы. Короче и проще, чем [`../../middle/general/01_topic_requirements.md`](../../middle/general/01_topic_requirements.md).

---

## Связность курса

- Каждая тема опирается на предыдущие и явно это говорит (`Как мы видели в теме N…`).
- В конце темы — блок **«Что дальше»**: одно-два предложения о следующей теме.
- Раздел начинается с короткого ввода: *почему* эти темы рядом.
- Сложность внутри раздела растёт от простого к прикладному.
- Нет блока «Связь со стеком Next / React / TypeScript».

Навигация в каждой теме:

- `← Предыдущая тема: [N — Название]`
- `→ Следующая тема: [N — Название]`
- по необходимости инлайн `🔗 Связь с темой N`

## Шесть блоков каждой темы (этот порядок)

| № | Блок | Назначение |
|---|------|------------|
| 1 | **Теория с аналогией** | Механизм простым языком |
| 2 | **Где это в реальном коде** | Браузер, `fetch`, простой скрипт Node — без React |
| 3 | **Паттерны** | 2–3 рабочих приёма, не middle-антипаттерны |
| 4 | **Вопросы** | Около 5 вопросов с короткими ответами |
| 5 | **Практическое задание** | Одна конкретная задача на чистом JS |
| 6 | **Решение с инсайтом** | Рабочий код + один ключевой вывод |

### Теория

- Минимум одна бытовая аналогия, затем переход к коду.
- Схема ASCII, если она объясняет механизм.
- Примеры — `.js` с комментариями.

### «Где это в реальном коде»

- Конкретные места: обработчик кнопки, разбор JSON, модуль `import`.
- Не упоминать хуки, JSX, дженерики TS, App Router.

### Паттерны

- Минимум **2**, лучше 3.
- Формат: так лучше не делать → так лучше → почему (одной проблемой, не лекцией по архитектуре).

### Вопросы

- Минимум **5** (не 9, как в middle).
- Формат `**Q{N}: Текст?**` и ответ в 3–5 предложениях, который можно произнести вслух.
- Без головоломок ради головоломок (`[] == ![]` и т.п.).

### Практика и решение

- Задание выполняется в `sandbox/js_sandbox` файлами `.js`.
- Решение с одним инсайтом: что запомнить навсегда.

## Чего в темах Junior нет

- TypeScript-аннотаций и обсуждения компилятора.
- React, Next.js, Redux, Zustand.
- Отдельной темы TDZ, глубоких прототипов, генераторов, WeakMap, дескрипторов, каррирования.
- Интервью-магии с `==` как ядра раздела про типы (достаточно `===` и короткого «почему `==` опасен»).
